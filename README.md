# Video Thumbs

Generate a tracker-style JPG contact sheet from a video file.

The generated image contains:

- Filename
- File Size
- Resolution
- Framerate
- Duration
- Evenly distributed thumbnails across the video
- Timestamp on each thumbnail

Designed for private tracker uploads and release presentation screenshots.

---

## Requirements

### macOS

Install FFmpeg and MediaInfo:

```bash
brew install ffmpeg mediainfo
```

Install Python dependencies:

```bash
pip install -r requirements.txt
```

## Basic Usage

Generate a contact sheet next to the source video:

```bash
python3 video_thumbs.py "/path/to/movie.mkv"
```

## Files Generated

For:

```text
Movie.mkv
```

the script generates:

```text
Movie.jpg
Movie_MediaInfo.txt
```

The contact sheet contains:

- Filename
- File Size
- Resolution
- Framerate
- Duration
- Screenshot timestamps

The MediaInfo file contains the complete MediaInfo output generated by:

```bash
mediainfo Movie.mkv
```

---

## Custom Output Folder

```bash
python3 video_thumbs.py \
    "/path/to/movie.mkv" \
    --output "/path/to/output"
```

Output:

```text
/path/to/output/
├── movie.jpg
└── movie MediaInfo.txt
```

## Screenshot Count

Generate 9 screenshots:

```bash
python3 video_thumbs.py \
    movie.mkv \
    --count 9
```

Generate 16 screenshots:

```bash
python3 video_thumbs.py \
    movie.mkv \
    --count 16
```

---

## Grid Columns

Three-column layout:

```bash
python3 video_thumbs.py \
    movie.mkv \
    --columns 3
```

Five-column layout:

```bash
python3 video_thumbs.py \
    movie.mkv \
    --columns 5
```

Rows are automatically calculated.

Partial last rows are supported.

Example:

```text
Count   : 10
Columns : 4

[ ][ ][ ][ ]
[ ][ ][ ][ ]
[ ][ ]
```

---

## Thumbnail Width

```bash
python3 video_thumbs.py \
    movie.mkv \
    --width 500
```

Default:

```text
400
```

## Timestamp Font Size

```bash
python3 video_thumbs.py \
    movie.mkv \

```

---

## Keep Temporary Screenshots

By default the script deletes the intermediate screenshots.

Keep them:

```bash
python3 video_thumbs.py \
    movie.mkv \
    --keep-temp
```

This leaves:

```text
screenshots/
├── shot_000.jpg
├── shot_001.jpg
├── ...
└── shot_011.jpg
```

## Validate Script

python3 video_thumbs.py \
